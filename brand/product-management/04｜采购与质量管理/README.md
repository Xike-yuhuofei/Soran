# 04｜采购与质量管理

管理采购订单、到货与质量事实。每个订单必须引用商品编码、**已冻结规格版本**和**已批准样品**。
- [采购订单台账.csv](./采购订单台账.csv)：跨订单总览；实际订单与合同放在私有空间。
- [质量异常与售后追踪.csv](./质量异常与售后追踪.csv)：闭环追踪到批次、责任人与改进验证。
- [采购订单与合同](./采购订单与合同/README.md)：订单文件的存放/命名规则。
- [检验与验收记录](./检验与验收记录/README.md)：验收证据及结果的存放/命名规则。

内部 ERP 如已管理真实交易事实，应以其数据为准；这里保留必要的业务决策与验收索引，不再建第二套交易真相。
