# 02｜单品开发

按品类放产品档案，每个**内部款式编号**对应一个子文件夹。候选供应商之间的询价、样品比较在该款式文件夹中集中记录，不按供应商拆分。

创建新款式时：
1. 先在 `01｜产品规划/SORAN 产品矩阵总表.csv` 分配内部款式编号。
2. 在对应品类中新建 `内部款式编号｜产品名称/`。
3. 从 `00｜管理规范与模板/模板/` 复制「单品立项书、供应商询价单、供应商报价比选、样品评审、产品规格确认书、变更记录」。
4. 每完成一个阶段，由品牌负责人确认通过并记录结果；未完成的字段留空。
5. 规格冻结后使用版本号管理，修改不得覆盖历史审批依据。

图片、测试报告、封样证明及真实报价应存放在**私有空间**，在私有单品档案中记录引用链接。
