# 01｜产品规划

这里决定「做哪些产品」，不是工厂技术规格库。
- [SORAN 产品矩阵总表.csv](./SORAN%20产品矩阵总表.csv)：每行一个内部款式（SPU），不是单个 SKU；未批准的款式仍可记录为机会池。
- [市场与竞品研究.csv](./市场与竞品研究.csv)：记录有来源的消费者需求与竞品证据，不把主观判断伪装成事实。
- [年度产品路线规划.csv](./年度产品路线规划.csv)：按优先级和里程碑排期。

统一单位：价格和到仓成本均按**销售单位**记录，例如「3 条/包」；折算时明确件数、运费、包装、增值税及渠道费用口径。不同销售单位不能直接比较。
真实数据不要写入公开仓库，复制本模板到私有工作区填报。
