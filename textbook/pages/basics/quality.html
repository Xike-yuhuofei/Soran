BASICS · QUALITY

性能、检测与质量标准

检测报告是品牌与工厂之间唯一不会说谎的语言。这一页教你三层功夫：看懂强制标准 GB 18401 的 A/B/C 分级与核心限值，明白贴身衣物最要命的十来个性能指标用什么方法测；认识产品标准家族在分等定价中的作用；再用一张缺陷图鉴学会「长相—成因—定责—怎么写进验货单」，并亲手完成一次 GB/T 2828.1 抽样判定演算。读完你能独立审查检测报告、主持一场有据可依的验货。

阅读时间 约 28 分钟 前置：针织面料与染整 标准数值以最新有效版本为准

01为什么要懂检测：品牌与工厂的共同语言

你和工厂隔着一张谈判桌，各自的说法都不可信：「我们质量很好」和「我觉得不好」都无法执行。能被双方共同执行的语言只有一种——标准 + 检测数据。规格书里写「耐湿摩擦色牢度 ≥3 级（GB/T 3920）」，验货时按方法标准测，出数据说话：达标收货、不达标退回，不需要吵。

内在质量
仪器说了算的部分：纤维含量、克重、缩水率、色牢度、起球、胀破强力、pH、甲醛等。它决定「穿三个月后还是不是一件好产品」，也是检测报告的主体。
外观质量
人眼 + 规则判定的部分：色差、疵点、缝制质量、对称性、线头污渍。它决定「开箱第一眼」，靠验货标准（缺陷图鉴 + AQL 抽样）管理。
分等制度
产品标准把质量分为优等品 / 一等品 / 合格品三档（部分标准另设等外品），每档对应不同指标门槛。等级写进合同就是质量承诺：收一等品的钱，就要交一等品的货。

对主理人，检测报告有三个用途：① 准入底线——强制标准不达标不得出厂销售；② 分等定价——等级与考核项写进合同与规格书；③ 纠纷仲裁——出货前封存留样与大货一致性的证据链，出问题时以第三方数据定责。

02强制底线：GB 18401-2010 与婴幼儿加严

GB 18401-2010《国家纺织产品基本安全技术规范》是纺织品的强制底线——不达标即不得生产、销售。它把产品按接触皮肤的程度与人群分三类：A 类（婴幼儿，36 个月及以下）、B 类（直接接触皮肤）、C 类（非直接接触皮肤）。你做的内裤、袜子、文胸、秋衣裤全部属于 B 类；婴幼儿贴身产品必须 A 类，并叠加执行 GB 31701-2015《婴幼儿及儿童纺织产品安全技术规范》（在 GB 18401 基础上加严，新增附件抗拉强力、绳带与边缘安全、残留断针等要求）。

关于标准版本

本页引用 GB 18401-2010、GB 31701-2015 及各方法标准时，均以写作时点的现行版本为准。标准会修订换版（限值、方法都可能调整），采购与验收合同中请统一写明「按现行有效版本执行」，并在每次大货检测前与检测机构核对版本号。教材不代替标准原文，出报告与定合同以标准原文为准。

03贴身衣物的核心性能指标与方法

强制标准只保证「无毒无害」，好穿耐用要靠下面这些性能指标。它们各有对应的方法标准——报告上「检测依据」一栏写的就是这些编号。先速览，再讲三个最值得深究的。

三个最值得深究的指标

水洗尺寸变化率（缩水率）：把面料按标准洗涤干燥前后对比标记点距离。针织物缩水的根源在染整（第 05 节讲过的定型与预缩），检测只是「验尸」。注意两个口径：面料缩率（进厂验布时测）与成衣缩率（缝制过程还会叠加），面料合格不等于成衣合格，两边都要测。

色牢度体系：它不是单一指标，而是一组「染色抵抗某种外界作用」的能力——耐洗（皂洗）、耐摩擦（干 / 湿）、耐汗渍、耐光，全部用灰卡评级。贴身衣物的真实考验是「汗液 + 摩擦 + 潮湿」的叠加，所以耐湿摩擦是最容易翻车也最值得加严的一项：深色活性染料棉布、酸性染料锦氨布都要盯。

拉伸弹性：定伸长拉伸后看回复率。同样标「弹力」，回复率 95% 与 80% 的裤子一个月后是两件产品。它由氨纶的品质（好的裸丝 vs 回收料）、含量与添纱结构共同决定——报价奇低的「高弹」面料，先怀疑氨纶。

04产品标准家族：分等的依据

强制标准管安全底线，产品标准（GB/T 推荐性国标、FZ/T 纺织行业标准）管「这个品类应该做到什么程度」：考核哪些指标、分几等、各等门槛多少、外观疵点如何判。它是你写规格书、定验收等级、打品质官司时引用的「品类宪法」。

三条使用要领：① 先选标准，再定等级——规格书首页写明「执行 GB/T 8878-2023，一等品」，所有考核项自动以此为框架；② 企标补位——功能宣称（抗菌、凉感、减震）若无对应国行标覆盖，备案企业标准并附第三方数据；③ 核对版本——标准号后面带不带年份、哪一年的版本，报价与检测前都要和工厂、检测机构三方对齐，避免「各说各话」（警惕引用已废止标准，如 FZ/T 73024-2014）。

05缺陷图鉴：长相 · 成因 · 定责 · 怎么写

验货的核心技能是把「感觉不对」翻译成「可追责的文字」。下面按五大类拆解贴身衣物最常见的缺陷：每类给你长相（怎么认）→ 成因（为什么会发生）→ 责任环节（找谁）→ 验货单怎么写。先约定：疵点按严重程度分主要疵点（影响穿着、安全或寿命，如破洞、跳针）与次要疵点（轻微外观问题，如轻微浮线），分类标准写进规格书，验货时按类计数。

花边勾丝蕾丝定形不足、设备 / 环境毛刺勾挂辅料厂或成衣厂「杯面勾丝 1 处，丝线已抽拉，计主要疵点」

装饰件 / 钩扣脱落缝钉不牢、拉力不达标成衣厂（工艺）「装饰件拉力低于企标值，全批返修后复验」（儿童产品执行 GB 31701 附件拉力要求）
常见误区：把所有问题都算到成衣厂头上

色花、缩水、螺旋（丝缕歪斜）、弹力衰减的根源都在面料环节；成衣厂只是最后一个「摸过货的人」。定责靠证据链：进厂验布记录 + 缸号留样 + 首件确认样 + 测试单。没有留样，纠纷时你说不清问题发生在哪一环——这也是下一节验货流程存在的意义。

06验货流程与 AQL 抽样判定

全流程五道闸

① 面料进厂
验布按 四分制评分：疵点按长度计 1–4 分（约 ≤7.5cm 计 1 分，每档递增，单码最高 4 分），每 100 平方码内总分 ≤28 分为常见合格线（可约定更严）。同时实测克重、幅宽，送测缩率与色牢度。
② 首件确认
大货开裁前按产前样做首件，尺寸、工艺、配色、辅料全项核对签字封样——大货以此为准，防「大货与样品不一致」。
③ 中查
裁剪与车缝过程中的巡检：查裁片丝缕、缝制张力、部位尺寸，问题在半成品阶段拦截，返工成本最低。
④ 尾查（终期抽检）
成品按 AQL 抽样判定（本节重点）。第三方验货（SGS / ITS / BV 等）与品牌自验都用 GB/T 2828.1 框架。
⑤ 检针与出货
检针机全数排查断针（含断针记录），装箱唛头核对，出具验货报告后方可出货。

AQL 抽样判定：从批量到接收 / 拒收

AQL（Acceptable Quality Limit，可接受质量限）的逻辑：不检查每一件，而是按批量随机抽取样本，数疵点个数与判定数比较。行业常用 AQL 2.5（主要疵点）/ 4.0（次要疵点），检验水平 II，正常检验一次抽样。三步查表：

一份合格的验货报告要素

  • 订单信息：款号、批量、抽样方案（批量 / 水平 / AQL / n / Ac / Re）、验货日期与地点。
  • 疵点分类统计：按缺陷图鉴分类计数，主要 / 次要分开，附编号照片。
  • 判定结论：接收 / 拒收 / 有条件接收，对照抽样方案写明依据。
  • 处理意见：返修、全检、让步接收（降级扣款）或拒收退厂，及复验安排。
  • 证据与签字：留样封存编号、双方签字——这是后续仲裁的证据链。

07主理人视角：读报告与建内控

如何读一份第三方检测报告

  1. 看资质章：报告应有 CMA 章（检验检测机构资质认定，中国市场出具具有证明作用的数据必须具备）；CNAS 章代表实验室通过国家认可、数据国际互认。无 CMA 的「检测数据」只能算工厂自测参考。
  2. 对样品信息：型号、颜色、批次、面料成分是否与你送检的大货一致——「套报告」（拿 A 货报告交 B 货）是常见把戏，核对样品照片与封样编号。
  3. 看判定依据与单项结论：每个项目是否写明标准号与版本、单项结论是「符合 / 不符合」还是只给数据；注意「仅对来样负责」的含义——报告只代表送检那一段布或那几件样。
  4. 核验真伪：向机构官网或客服提供报告编号核验；警惕格式怪异、机构查无此号的报告。
  5. 选项目：常规套装 = GB 18401 全项 + 产品标准核心项（缩率、色牢度、起球、顶破 / 拉伸）+ 纤维含量定量；有功能宣称加测对应功能标准；深色必加湿摩擦。
主理人视角：建立 Soran 内控标准的三步思路

国标行标是「及格线」，品牌的品质口碑来自「比及格线严一点」。三步搭建：① 从严抓「贵」的指标——消费者能用身体感知、且直接决定复购的：pH 收窄至 4.0–7.5、耐湿摩擦加严 0.5 级、缩率 ±4%、甲醛内控 ≤50 mg/kg（以上均为示例值，按 Soran 定位校准）；② 从宽放「贵而无感」的项——耐光等贴身场景弱相关的项目按标准下限即可，把钱花在刀刃上；③ 写成文件——内控限值进规格书与采购合同，检测不合格的处理路径（退修 / 降级 / 拒收）预先约定，标准才有牙齿。

常见误区：A 类标注滥用与「婴儿可用」营销

吊牌标「GB 18401 A 类」就必须按 A 类限值检测并全部符合，婴幼儿产品还要执行 GB 31701——拿着 B 类报告标 A 类，或文案写「婴儿可用」但实际按成人 B 类生产，都属违规标注，市场监管抽查与职业打假的高发区。同理慎用「抗菌率 99%」「零甲醛」这类无报告支撑的绝对化宣称。Soran 的原则：宣称的每一个字，都要能在报告里找到对应的行。

共同语言
标准 + 检测数据才能执行；内在质量靠仪器、外观质量靠验货规则，等级（优等 / 一等 / 合格）写进合同就是承诺。
强制底线
GB 18401：内裤袜子文胸 = B 类；甲醛 ≤75、pH 4.0–8.5、色牢度 ≥3 级、异味禁有、芳香胺 ≤20 mg/kg；婴幼儿叠加 GB 31701。
性能抓手
缩率 ±5%、耐湿摩擦（深色必测）、起球、胀破、弹性回复率与纤维定量（含量 >10% 允差 ±5、≤10% 允差 ±3）——「穿三月后还是不是好产品」全在这组数据里。
产品标准
FZ/T 73001-2016（袜）、GB/T 8878-2023（针织内衣，含内裤）、FZ/T 73012-2017（文胸）是分等与考核框架，引用前核对版本。
缺陷定责
色差 / 染整类 → 面料厂；织造类 → 面料厂织造；缝制 / 辅料类 → 成衣厂；定责靠留样与记录，不靠嗓门。
抽样判定
批量 → 水平 II → 字码 → n → AQL → Ac/Re，计数规则非百分比；任一超 Re 即拒收；报告五要素齐全才算闭环。
读报告
CMA 章是效力门槛；对样品信息防套报告；单项结论看标准号与版本；报告编号可向机构核验。
内控思路
严在身体可感知（pH / 湿摩 / 缩率），宽在无感项目；宣称的每个字都要有报告行对应。
