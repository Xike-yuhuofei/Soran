01教材定位：学什么、学到什么程度

阅读前想一想不懂行业术语时，能不能先描述自己想解决的顾客问题？

想象你第一次走进贴身衣物工厂：供应商说这款是“80S 莫代尔、无痕切边、四针六线”，你听懂了每个字，却不知道它们分别描述原料、面料还是工艺，也不知道该不该多付钱。本教材要解决的，就是从“听到一个词”到“作出可验证的产品判断”之间的距离。

是什么
一个术语、一种材料、一道工序的准确定义与边界。（基础层）
为什么
为什么这个品类要用这种材料、这种结构、这道工艺——背后的功能与成本逻辑。（理解层）
怎么比
两件看似相同的商品，品质差异在哪里，如何用可验证的方法比较。（判断层）
怎么定
作为品牌主理人，如何把这些判断转化为选品决策、规格书、验收标准与供应商对话。（决策层）

学习从三个问题展开：产品为什么要这样设计？这个方案与替代方案差在哪里？供应商需要拿什么证据证明？第一篇建立纤维、纱线、针织、质量与供应链的共通框架，随后进入内裤、袜子、文胸的具体结构和工艺，最后完成实战选品。第一次学习可以按顺序走；遇到紧急采购问题，也可以先查对应章节，再补前置知识。

主理人视角

你的目标不是自己操作袜机或编写染整配方，而是具备主理人的判断能力：看懂样衣和参数，能把“柔软”“耐穿”“不勒”转成明确要求，知道哪些判断能通过试穿验证、哪些需要检测，最后能把成本与零售价值联系起来。涉及公式、工艺机理和标准的专业深入部分，可在理解基础层后再读。

02知识体系总览

阅读前想一想一条内裤从纤维变成成衣，经过哪些决策和验证节点？

把知识体系想成一条从原料走向消费者的链：纤维 → 纱线 → 面料 → 成衣结构 → 生产检验 → 用户体验与复购。下方地图按学习主题归类；它并不是互不相干的六个术语盒子。例如消费者反映袜口勒脚，根因可能在橡筋、罗纹宽度、穿着围度或工艺张力，不能看见“氨纶”就直接换配方。

03选择你的学习路径

阅读前想一想你此刻是要系统入门、开发一个 SKU，还是核验一份报价？

准备一条普通内裤、一双日常袜子和一件文胸，先摸、看、拉伸、翻到背面观察缝线，再带着问题学习。不必为了完成阅读进度而硬背全部专业词。以下三种路径对应不同任务，所需时间因你的基础和实物练习频率而异。

适合：刚进入行业、希望建立完整的技术与经营认知。先读通用基础，再按内裤、袜子、文胸分别实践，最后学习供应商验厂与选品决策；每读完一节，用一件实物解释对应知识。

  • 第 1 周：通读第一篇全部五章（产品基础 → 供应链），完成每章自测。这一遍不求记住所有参数，只需建立概念地图。
  • 第 2 周：内裤篇 + 袜子篇（每篇 2 章，篇幅较短），同步做实物拆解练习。
  • 第 3–4 周：文胸篇三章（重点，建议精读两遍——第一遍懂结构，第二遍懂取舍），随后立即学习第五篇选品实战。
  • 贯穿：每次读完一章，用手边产品对照验证 3 个知识点；用首页搜索检查自己能否解释核心术语。

适合：正在考察供应商或准备开发具体 SKU。先读目标品类的结构、材料与工艺，再回到“纤维与纱线”“针织面料”“质量检测”补齐看不懂的参数，带着问题去现场核验。

  • 先读：第一篇的「纤维与纱线」「性能检测与标准」「生产制造与供应链」三章（跳过深水区，抓主干）。
  • 再读：你首发品类的对应篇目（如先做内裤，读第二篇全部），完成该篇自测。
  • 必读：第五篇「品质判断」中的规格书模板与「供应商考察」中的考察清单——这两样是可以直接带去工厂用的。
  • 补课：遇到听不懂的术语立刻用 / 搜索或查术语索引，回来把关联章节补上。

适合：已经有样衣、报价表或检测报告，需要快速验证差异。先打开相应的对比表、术语索引和采购清单，找到判断依据，再回读专业原理，避免拿一个参数替代整体品质。

  • 验货出问题 → 「性能、检测与质量标准」的缺陷图鉴 + 对应品类篇的品质章节。
  • 报价看不懂 → 「生产制造与供应链」的成本结构 + 第五篇的成本拆解工具。
  • 打样不理想 → 对应品类篇的工艺章节，先看「问题成因」小节再回复工厂。
  • 新品类立项 → 先读该品类篇的「选品判断」小节，再用规格书模板起草技术要求。

04教材功能与使用方法

阅读前想一想哪些数据是教学参考，哪些信息可直接用于合同与验收？
①术语系统
  • 正文中带金色虚线下划线的词（如 旦尼尔、包覆纱）可以悬停或点击查看释义卡片。
  • 释义卡内的「相关 →」可跳转到关联术语，适合顺藤摸瓜式学习。
  • 全部术语集中在「附录 · 术语索引」，支持按分类浏览。
②搜索
  • 按键盘 / 键或点左侧搜索框，可同时检索术语定义与章节正文。
  • 搜索结果直接跳转到具体小节，适合「工作手册」式使用。
③学习进度
  • 每页按小节自动记录阅读进度，读完一整页侧栏会打 ✓。
  • 进度保存在当前浏览器中（localStorage），换浏览器或清理数据会重置。
④自测（知识覆盖型）
  • 全书 193 道题按「知识点」组织：每题标注 L1 识记 / L2 理解 / L3 分析 / L4 应用 / L5 综合决策 五个认知层级（题号旁的彩色徽标）。
  • 核心知识点必考、从多角度考查，同一概念会以场景题、计算题、决策题反复出现——请把它当「体检」而不是「考试」。
  • 章末有知识点覆盖面板：显示每个知识点的掌握状态与覆盖缺口，答错附完整解析（含错误选项辨析）。
  • 答案与得分自动保存在本机，可随时重做。
关于数据严谨性

这套教材的图表、模拟报价和计算器是教学工具，不是供应商报价单或产品合格证明。示例成本用于练习成本拆解，材料参数用于建立量级感；最终采购必须核对明确的成分与规格、现行有效的标准、同条件实测数据及签样要求。遇到“高支”“抑菌”“凉感”等宣称时，先确认它在描述什么，再要求对应的证据。

05三个学习习惯，效果翻倍

阅读前想一想怎样用两件同款样衣做一次有记录、可复现的比较？

习惯一：拆，是最快的学习

拿到样衣，先把它当成待研究的产品，而不是先判断“喜欢不喜欢”。用五个观察问题起步：成分标签写了什么？边口和接缝怎么做？关键部位厚薄、弹性和位置如何？拉伸后能否回复？洗后尺寸和表面会怎样？称整件重量可以比较用料，但整件克重不能直接等同于面料每平方米克重，若要判断面料克重，应另按规范取样。

习惯二：永远做对比

学材料最有效的方式是控制变量做比较。例如拿两条同款、同码的三角裤，分别记录腰头宽度、裆宽、面料手感与试穿勒痕；再把洗后结果加入比较。比较袜子针数时则要同时确认筒径、纱支和毛圈结构，否则容易把几项差异错认成“针数好坏”。

习惯三：带着问题下工厂

把供应商说过但你暂时没听懂的词记录下来，并写出它所在的句子。回来先判断这个词属于纤维、纱线、面料、结构、工艺还是标准，再追问：它影响什么性能？有什么替代方案？用什么样品或报告验证？带着问题学习，比背一张术语表更容易转化为谈判能力。

常见误区

学习不以“记住多少名词”作为终点，而以能否独立完成一个判断为准。每章推荐完成一张小记录：产品目标 → 可选方案 → 风险与成本 → 验证证据 → 暂定决策。当你能向另一位没有行业经验的人解释为什么这样选，并指出尚未验证的部分，这项知识才算真正用上。

06学完各篇，你能做什么

阅读前想一想准备好哪件实物、哪三个问题，就可以开始第一篇？
五篇学习路线与能力产出（教学规划，非承诺）。按顺序读可建立从材料到选品的完整框架。
完成你将能够
第一篇 通用基础看懂成分标与检测报告；听懂供应商的行话；判断一份报价单里的材料是否合理；知道问什么问题不会被绕过去。
第二篇 内裤独立完成内裤款式的工艺路线选择（车缝/无痕/无缝）、底裆方案与成本估算；识破常见偷工点。
第三篇 袜子判断针数、克重、加固是否与售价匹配；写出袜子规格书；与大唐/义乌袜厂有效沟通。
第四篇 文胸理解承托逻辑与版型语言；选定工艺路线（车缝/模压/无痕/无缝）并评估打样；判断试穿问题的工艺成因；与汕头模杯/车缝厂对等沟通。
第五篇 选品实战建立产品技术规格书与验收标准；执行系统化的工厂考察与样品评审；用成本拆解与供应商谈判；形成符合 Soran「高品质、高质价比」定位的选品标准。

现在可以从《产品基础与人体工学》开始。学习时随手拿起一件实物，先观察“哪里舒服或不舒服”，再寻找背后的材料、结构和工艺原因。下方自测用来检查判断依据，而不是测试术语记忆速度。

先试两题：感受一下自测的风格（知识覆盖型 · L1-L5）

  • 手感比普通莫代尔柔滑，可按兰精面料下单
  • 报价高出一倍，改用普通莫代尔以控制成本
  • 厂家从业多年，口头保证可视为材料来源证明
  • 索取兰精授权或采购凭证，并送第三方定量检测
  • 针数差异主要影响机台效率，难以单独解释棉纱成本差
  • 一款用长绒棉高支精梳纱，另一款用普通精梳纱
  • 一款袜口用双包锦纶包覆氨纶，另一款用普通橡筋
  • 贵款标注进口氨纶，实际与便宜款氨纶同质同源
  • 先读第一篇三章主干，再读袜子篇，最后用第五篇工具
  • 直接精读袜子篇，第一篇与第五篇可在谈判后再补
  • 先把 140 多个术语背完，再开始安排与工厂谈判
  • 重点看第五篇谈判技巧，生产与材料问题交由工厂判断
