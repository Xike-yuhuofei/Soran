文胸 · 承托原理、分类与结构

文胸是三个品类中结构最复杂、版型与人体耦合最深的一件：它要在没有肌肉可借力的部位，用面料与几根钢圈完成「整形外科」级的工作。本页先讲清承托的物理逻辑——为什么承托主要靠底围而不是肩带，再建立四维分类矩阵，逐部位拆解一件有钢圈文胸的解剖，深讲尺码体系与姐妹码，最后落到八个高频试穿问题的「现象→成因→调整」诊断表。

阅读时间 约 30 分钟 前置：第一篇 · 通用基础 建议准备一件旧文胸边读边拆

01承托的科学：重量去哪儿了

先回到人体。乳房的主体是罩杯要包裹的两类组织——乳腺腺体与脂肪，它们「坐」在胸大肌表面，但乳房内部没有肌肉：唯一的内部支撑是皮肤和一条条叫库珀韧带（乳房悬韧带）的结缔组织束。韧带不是橡皮筋，被长期反复拉伸（妊娠哺乳、年龄、高强度晃动）后不可逆。这就是文胸这个品类的存在理由：乳房的「肩膀」必须由外部结构来当。

外部结构只有两条路径可以走：

路径①
底盘支撑
由下扒、钢圈、侧比与后比组成一个环绕胸廓的「稳定环」，把罩杯变成安放在胸廓上的货架——乳房重量沿「罩杯→钢圈→下扒→底围环→胸廓」传导。这是主承托路径。
路径②
悬吊
肩带把杯口向上提拉，主要负责杯口贴胸、抑制晃动，并分担一部分重量——罩杯越大、运动越剧烈，肩带分担占比越高，但它始终是辅助路径。

为什么「承托靠底围，不靠肩带」

一条紧贴胸廓的弹力环带（下扒＋后比），靠环向张力＋与皮肤间的摩擦力提供支撑——它不随耸肩、摆臂、驼背而波动，受力稳定。肩带则相反：张力随肩部动作持续变化，且压在斜方肌与肩峰上，调得过紧的直接后果是肩颈酸胀与勒痕，而不是更好的承托。行业通识是：合体状态下，大部分承托由底围系统完成，肩带负责「稳」而非「扛」（具体比例随罩杯与款式变化，无统一数值，教学上记住「底围为主、肩带为辅」即可）。

由此得到两条实用的判断：第一，试穿时先看底围——平贴躯干、可插入两指、深呼吸不勒，后背处于最低扣位略紧（弹力面料穿洗后会松弛，新衣要「新时偏紧」）；第二，凡是「承托不好」的反馈，第一嫌疑人是底围失配，而不是肩带不够紧。

常见误区

「承托不好就把肩带调紧」。底围失配时，罩杯整体下沉、杯口离开胸壁，消费者感受到的是「晃」，于是去收紧肩带——这等于让肩颈替底围上班：晃动没有解决，肩痛先来了。正确的问诊顺序永远是：先查底围松紧与落位，再查杯容，最后才动肩带。这个顺序请原样写进你的客服话术与试穿引导。

02分类矩阵：四个维度看款式

03结构拆解：一件有钢圈文胸的解剖

把一件有钢圈文胸平铺在桌上，你会看到十来个部件；每个部件同时承担「功能」与「风险」——功能没做到位是舒适与承托问题，做过了头是成本与压感问题。点击下图编号，查看每个部位的功能、工艺要点与常见问题。这是全页的核心一节，建议对照实物逐一找到它们。

杯面剪接：一片、两片还是三片

车缝杯的杯面由裁片拼成：一片杯靠面料弹性成型，外观干净但立体度有限；两片杯用一道斜向分割线做出指向性，是日常款主流；三片杯再多一道水平剪接，包容与支撑最好，常见于全罩杯与大杯款。剪接线每多一道，裁剪与车缝成本上升，但「杯是有形的」——高档感与合体度都来自这些看不见的分割。

钢圈槽的两种做法

车缝槽
下扒与杯底之间用双层布料车出槽道，端头打结加固。传统做法，成本可控；品质看线迹密度与端头封口。
胶条封口
用热压贴合胶条封闭槽口，外观更平薄；品质看胶条剥离强度与耐洗性——封口开胶与车缝脱圈一样，都属严重缺陷。

04尺码体系深讲：字母与数字的真正含义

文胸尺码由两部分组成：数字是下胸围（乳房下缘水平围长，国内主流 5cm 一档：65 / 70 / 75 / 80 / 85 / 90），字母是罩杯——上胸围（乳头水平最丰满处）减下胸围的差值：

国内主流口径：上下胸围差与罩杯字母对应（教学参考，各品牌存在±1-2cm 的版型差异）
上下胸围差约 10cm约 12.5cm约 15cm约 17.5cm约 20cm
罩杯字母ABCDE

关键在于：同字母不同下围，杯容完全不同。75B 与 95B 的「B」只表示差值接近 12.5cm，但 95B 的杯面积极大——因为胸腔本身更粗，同样差值对应的立体容积大得多。

姐妹码：上移一围，下移一杯

既然底围上移一档（+5cm）时杯容会自然变大，要保持容积不变就把字母降一档：75B → 80A；反过来底围下移一档就升一档字母：75B → 70C。这组「容积守恒」的等价尺码叫姐妹码。它的实战价值：某款 75B 底围勒，先试 80A 而不是 75C——底围加一档同时杯容不变，才是对症的调整。

深入理解 · 姐妹码为什么「容积守恒」

罩杯的容积近似等于「差值 × 胸廓周长的函数」。下围 +5cm 意味着胸廓骨架更大，同样的差值摊在更大的周长上，立体容积自然增长；字母降一档（差值 −2.5cm）刚好抵消这个增长。理解了这一点，就明白为什么「70C 的胸 ≠ 80C 的胸」——也明白为什么欧美品牌按英制体系（起点、级差都不同）做的尺码，照搬过来必不合体。

为什么尺码只是起点

因为决定合体的是版型，不是尺码标签：同一副身体，甲品牌 75B 合体、乙品牌 75C 才合体是常态；杯深、杯宽、钢圈开口这些版型参数，尺码表上一个都体现不出来。更根本的是胸型——圆盘、半球、圆锥、水滴、下垂、外扩，各自的选杯逻辑不同（圆锥配浅杯、外扩配高侧比、下垂配全罩杯＋宽下扒）。所以专业的尺码建议永远是「尺码定范围，胸型定杯型，试穿定最终」。

主理人视角

行业普遍经验：文胸试穿问题约七成来自尺码错配（经验值，各渠道数据差异大，此处标注为经验参考，非实测统计）。这意味着文胸品牌的边际动作里，「教育」比「产品」优先级更高：详情页放测量教学视频、客服按「底围→杯容→杯型」顺序问诊、退货原因里单独归一档「尺码不合」并按月分析——这些动作不花模具钱，却直接压低退货率。剩下三成的问题才是版型与工艺，靠打样迭代解决（见工艺篇）。

06本页小结与自测

承托原理
乳房无肌肉、悬韧带不可逆；主承托走「底围环→胸廓」（下扒＋钢圈＋后比），肩带只管稳定杯口——「承托不好先查底围」。
分类框架
钢圈（有 / 无 / 软）× 覆盖（三角 / 1-2 / 3-4 / 全）× 厚度（超薄到厚）× 形态（背心 / bralette / 运动 / 哺乳 / 塑身），四维短句即定位。
结构十件
罩杯（杯面 / 杯里 / 棉杯）、捆条、鸡心、下扒、钢圈槽、侧比（含胶骨）、后比、肩带（前后长＋调节扣）、背扣、花边——部位即功能，边口即风险。
尺码体系
下胸围 5cm 档 × 上下差值定字母；同字母不同围杯容不同；姐妹码「上移一围下移一杯」容积守恒；尺码只定范围，版型与胸型定杯型。
诊断顺序
底围松紧与落位 → 杯容（空杯 / 压胸）→ 杯宽与侧比（跑杯）→ 肩带最后动；卷边等杯口问题先怀疑捆条张力（工艺）。
经营含义
约七成试穿问题（经验值）是尺码错配——教育（测码教学、问诊话术、退货归因）是文胸品牌 ROI 最高的运营投入。
  • 肩带还不够紧，指导顾客再收紧一档
  • 先查底围：底围松则支撑环失效、肩带被迫代偿；应先让底围平贴稳定，再定肩带松紧
  • 推荐换更宽的肩带款式，宽肩带就不晃了
  • 告知顾客轻微晃动是正常现象，所有文胸都这样

  • 改穿 70C：小一档底围更贴身
  • 改穿 80A：底围加一档、杯降一档，杯容基本不变的姐妹码
  • 改穿 85B：底围多放两档肯定松快

  • 杯容偏小：先升一档杯再看
  • 肩带过松导致：收紧肩带即可解决
