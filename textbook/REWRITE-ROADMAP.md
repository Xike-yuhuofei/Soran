> 本文件记录“正文实质重写”的进展。之前的 V3 统一导学卡和排版工程 **不等于正文完成重写**。

## 教学定位

面向**完全没有纺织、服装工程或贴身衣物行业知识的品牌主理人**。每章遵循：
1. 用一件真实商品或消费者痛点引出问题。
2. 用生活语言解释概念，再给严谨定义和适用边界。
3. 分开解释纤维、纱线、面料、结构、工艺、性能，不将一种材料直接等同于成品质量。
4. 提供有条件的对照、错误选材案例和供应商沟通方法。
5. 将学习结果落实为可记录、可验证、可写入规格书的决策依据。

正文宽度与响应式布局沿用已验收的 V3 标准；不得修改共享 CSS/JS 破坏其他课程。

## 每章验收

- [ ] 全部原有教学叙述段落逐段改写，审查每张表格、图注、提示框与知识小结是否仍一致。
- [ ] 重要术语首次出现先解释再使用；避免新术语定义又依赖多项未解释术语。
- [ ] 每个主要小节至少一次将知识用于内裤、袜子、文胸或供应商场景。
- [ ] 明确误区与适用边界，纠正不可证实的绝对结论和错误公式。
- [ ] 审查本章自测题与重写正文是否一致，若修改选项需遵守“四项同构同强”及逐项解析规则。
- [ ] 保留原页面 `data-sec`、`data-quiz`、相关术语引用、笔记与学习进度接口。
- [ ] 原页面图表和交互不丢失；Chromium 390/768/1024/1440/1920px 关键宽度检查，并留存截图。
- [ ] CI 全部通过后 PR 自动合并 main，失败不得绕过。

## 完成定义

只有正文和专业内容经过完整改写与审查，才可把一章标注为“已重写”。
仅增加 V3 导读、切换按钮或 CSS 版式的页面仍保持“待重写”。
